# Scars: what this plugin's doctrine was learned from

This is SCOUT's own incident log, not an adopter's. It documents what the doctrine in this plugin
cost to learn, before it was doctrine. Each entry, when one lands here, is written generically: no
product, company, or domain named, because the lesson has to survive leaving the specific incident
behind.

This file is separate from an adopter's own `.monkeys/scars.md`, which RAID and FORTRESS generate
and fill in as the adopter's own incidents happen. Don't confuse the two.

SCOUT is new as of this pack's Phase 1 build. No incident has happened on it yet, so this log is
honestly empty rather than seeded with a plausible-looking example. It fills in the same way RAID's
and FORTRESS's did: after something actually goes wrong, not before.
